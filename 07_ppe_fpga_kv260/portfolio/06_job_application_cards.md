# 자소서 소재 카드

## 카드 A. 예상하지 못한 문제 해결

**상황**: C2f Block Design이 합성 이후 Implementation/Routing 단계에서 실패했습니다.

**행동**: 로그를 제어·데이터·Clock/Reset·자원 문제로 분류하고, 최소 구성을 기준으로 연결을
단계적으로 복원했습니다. 매 변경 후 DRC와 구현 상태를 비교했습니다.

**결과**: DRC Error 0과 Bitstream 생성 성공을 확인했습니다.

**직무 연결**: 장비 장애에서도 Alarm과 도면을 기준으로 범위를 좁히고 조치 후 상태를 재검증하겠습니다.

## 카드 B. 빠른 학습

**상황**: HLS, AXI DMA, Vivado IP Integrator, KV260을 짧은 기간에 함께 다뤄야 했습니다.

**행동**: 제어 경로와 데이터 경로를 나누고, IP 단위 검증에서 전체 통합으로 학습 범위를 확장했습니다.

**결과**: HLS IP 분석부터 Vivado Bitstream 및 PYNQ Overlay 검증 단계까지 수행했습니다.

**직무 연결**: 신규 장비도 매뉴얼, 도면, 로그, 측정값을 연결해 빠르게 구조화하겠습니다.

## 카드 C. 품질 중심 사고

**상황**: 프로그램이 종료되고 완료 신호가 발생해도 FPGA 출력이 예상값과 다를 수 있었습니다.

**행동**: 레이아웃, 주소, 전송 길이, 양자화 조건을 분리하고 Golden Model과 단계별 비교했습니다.

**학습**: 장비의 정상 종료와 결과물의 품질 정상은 별개의 판정입니다.

**직무 연결**: 설비 복구 후에도 계측값과 제품 결과를 함께 확인하겠습니다.

## 카드 D. AI 도구 활용

**상황**: 많은 EDA 로그와 반복 명령을 제한된 시간에 분석해야 했습니다.

**행동**: Codex로 오류 후보와 실험 순서를 구조화하고, 모든 판단은 실제 리포트와 보드 출력으로 검증했습니다.

**결과**: 분석 이력과 수정 근거를 재사용 가능한 문서로 남겼습니다.

**직무 연결**: 자동화 도구를 적극 활용하되 최종 판단은 현장 데이터로 내리겠습니다.
